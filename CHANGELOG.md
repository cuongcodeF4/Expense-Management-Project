# Changelog

All notable changes to this project are documented here.

This changelog follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) and [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.1.0] - 2026-07-12

### Added

- Add, remove, and restore income and expense categories.
- Use custom categories in transactions, budgets, reports, and exports.

### Improved

- Improve data saving, sign-out, and app state handling.
- Improve responsive layouts for budgets and categories.
- Improve keyboard navigation and screen-reader support.

## [1.0.0] - 2026-04-05

### Added

- Android and web applications for expense management.
- Expense creation, editing, and deletion.
- Expense categorization, summaries, and analytics.
- Firebase integration for the web app.
- Project documentation and license.
